Data sources & privacy

Data comes from the public GitHub REST API (api.github.com), cached in your browser session for 10 minutes to stay under its unauthenticated rate limit. Requests go straight from your browser to the named service, without cookies or an API key; that service sees your IP address as in any web request. Everything received is treated as untrusted text and shown with safe DOM methods. Nothing is sent to this site, and this preview page is not indexed by search engines.
