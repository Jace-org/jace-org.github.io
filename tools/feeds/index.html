What an Atom feed for the blog would look like, generated here from the post index.

Static sample file

Sample feed.xml



How it would work


The blog generator already writes blog/posts.json with a title, date, tags and excerpt for each post. A feed is the same list in XML: one entry per post with a link, an id, a date and a summary. Readers and aggregators poll that file and show new posts without anyone visiting the site. This preview builds the XML in your browser from the live index; a real feed would be written once by the generator and served as a static file.


Data sources & privacy


The post index is read from this site (blog/posts.json); no third party is contacted. Requests go straight from your browser to the named service, without cookies or an API key; that service sees your IP address as in any web request. Everything received is treated as untrusted text and shown with safe DOM methods. Nothing is sent to this site, and this preview page is not indexed by search engines.
