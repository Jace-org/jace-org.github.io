Project badges

Release, build and last-push badges for each public project, drawn locally from live data.

Data sources & privacy

Data comes from the public GitHub REST API. This site's data service fetches it once an hour, so your browser never contacts GitHub and GitHub never sees your IP address. Badges are drawn in this page as inline SVG; no badge image service is used. Your browser only talks to this site's data service, without cookies or an API key. Everything received is treated as untrusted text and shown with safe DOM methods. Nothing is sent to this site, and this preview page is not indexed by search engines.
