    How it works

    A webmention is a notification from another website that says "I linked to your page". The free service webmention.io receives them for this site and exposes them as JSON. This page reads that JSON, checks every field, and shows it as plain text. Nothing a stranger writes is ever treated as HTML.

    Data sources & privacy
    

    This page calls webmention.io (a public API, CORS enabled) from your browser, so that service sees your IP address like any website. It sends only the list of this site's own post addresses. Mention text is untrusted, shown as plain text, truncated, and only https links are made clickable. Avatars are not loaded.
